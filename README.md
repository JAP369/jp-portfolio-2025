# JP Portfolio 2025 🚀

A modern, responsive portfolio website showcasing the work and expertise of Jonathan Austria Paita - Full-Stack Developer & Product Manager based in Hong Kong.

## 🌟 Features

- **Modern Tech Stack** - Built with Next.js 16, React 19, TypeScript & Tailwind CSS
- **Smooth Animations** - Powered by Framer Motion for engaging user experience
- **Fully Responsive** - Mobile-first design that looks great on all devices
- **SEO Optimized** - Semantic HTML and meta tags for better search engine visibility
- **Performance Focused** - Optimized with Turbopack and modern React features
- **Interactive Sections** - Scroll-based animations and hover effects throughout

## 📋 Sections

1. **Hero Section** - Eye-catching introduction with animated gradient background
2. **About** - Personal story and professional journey
3. **Projects** - Showcase of featured work and projects
4. **Skills** - Horizontal scrolling carousel of technical expertise
5. **Experience** - Timeline of work history and achievements
6. **Contact** - Get in touch section with social links

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/JAP369/jp-portfolio-2025.git
cd jp-portfolio-2025
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🛠️ Available Scripts

```bash
npm run dev          # Start development server
npm run build        # Build for production
npm run start        # Start production server
npm run lint         # Run ESLint
```

- **Animations:** Framer Motion

## 🎨 Customization

To customize the portfolio for your own use:

1. Update personal information in `HeroSection.tsx`
2. Modify projects in `ProjectsSection.tsx`
3. Update skills in `SkillsSection.tsx`
4. Change work experience in `ExperienceSection.tsx`
5. Update contact links in `ContactSection.tsx`
6. Adjust colors in `tailwind.config.ts`
